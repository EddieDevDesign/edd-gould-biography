
# Edd Gould Biography

An interactive biography website dedicated to Edd Gould,
the creator of Eddsworld.

Built with React, JavaScript, and CSS as an independent
extension of an Advanced Web Programming class project.

## Features

- Responsive layout
- Interactive photograph gallery
- Eddsworld milestones timeline
- Collapsible table of contents
- Filterable filmography
- Working citations and references
- Reading progress indicator
- Back to Top button

## Technologies

- React
- JavaScript
- HTML and CSS
- Vite

## About

This project began as a classroom exercise and was
expanded independently to explore React components,
state management, effects, responsive design, and
interactive user interfaces.

This is an unofficial educational project and is
not affiliated with Eddsworld.

Biographical content is adapted from Wikipedia
and other attributed sources.
